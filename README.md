# Homebrew Tap for AnnoyO

Install [AnnoyO](https://github.com/jooojo/sir-annoy-o), a native macOS menu bar Bilibili audio player:

```bash
brew install --cask jooojo/tap/annoyo
```

AnnoyO is currently ad-hoc signed and has not been notarized by Apple. macOS may block the first launch. If you trust this distribution, open **System Settings → Privacy & Security** and choose **Open Anyway**.

## Update

```bash
brew update
brew upgrade --cask annoyo
```

## Uninstall

```bash
brew uninstall --cask annoyo
```
